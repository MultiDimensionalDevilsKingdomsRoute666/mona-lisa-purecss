## Summary

A fork of [purecss-co/mona-lisa](https://github.com/purecss-co/mona-lisa). The Mona Lisa recreated in pure HTML and CSS.

## What's inside

`index.html`, `css/`, `sass/` (the source styles) and `screenshot.png`.

## How to view or run it

Open `index.html` in a browser. To edit the styles, run `npm install` and use the Sass scripts in `package.json`.
